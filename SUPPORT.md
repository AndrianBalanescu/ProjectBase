# Support

ProjectBase is volunteer-maintained alpha software. Community support is best-effort. There is no hosted service, SLA, guaranteed response time, or paid support channel.

## Before asking

1. Read the [README](README.md), [known limitations](README.md#known-limitations), and [existing issues](https://github.com/AndrianBalanescu/ProjectBase/issues).
2. Use the latest revision only after backing up and testing the upgrade in your environment.
3. Remove credentials, tokens, private URLs, personal data, and database contents from logs or examples.

## Where to ask

- Reproducible defects: use the [bug report form](https://github.com/AndrianBalanescu/ProjectBase/issues/new?template=bug_report.yml).
- Small, in-scope product proposals: use the [feature request form](https://github.com/AndrianBalanescu/ProjectBase/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue.
- Contributions: read [CONTRIBUTING.md](CONTRIBUTING.md).

General deployment troubleshooting can be opened as an issue when it concerns the repository's documented configuration and includes enough detail to reproduce. Questions about custom infrastructure, third-party products, or bespoke integrations may be closed or redirected.

## Useful diagnostic information

Include the ProjectBase revision or version, installation method, host OS and architecture, relevant sanitized configuration, exact steps, expected and actual behavior, and sanitized logs. A minimal reproduction is more useful than a screenshot alone.
